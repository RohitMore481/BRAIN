# Oxford Battery Degradation Dataset

Place Oxford Battery Degradation Dataset files in this directory.

## Source & Download
Download the dataset from the Oxford University Department of Engineering Science Battery Intelligence Laboratory.

## Required Datasets & Battery Files

Ensure the following cell data profiles are placed in this folder:

- `Cell1.mat` / `Cell1.csv`
- `Cell2.mat` / `Cell2.csv`
- `Cell3.mat` / `Cell3.csv`
- `Cell4.mat` / `Cell4.csv`
- `Cell5.mat` / `Cell5.csv`
- `Cell6.mat` / `Cell6.csv`
- `Cell7.mat` / `Cell7.csv`
- `Cell8.mat` / `Cell8.csv`

## Usage
The Oxford dataset provides characterization tests and driving profile aging measurements for thermal and electrical model parameter calibration.

> **Note**: MAT and CSV data files are excluded from version control via `.gitignore`.
