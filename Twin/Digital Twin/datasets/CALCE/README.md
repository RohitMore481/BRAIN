# CALCE Battery Dataset

Place Center for Advanced Life Cycle Engineering (CALCE) battery dataset files in this directory.

## Source & Download
Download the dataset from the University of Maryland CALCE Battery Research Group repository.

## Required Datasets & Battery Files

Ensure the following battery cycle data files are placed in this folder:

- `CS2_33.mat` / `CS2_33.csv`
- `CS2_34.mat` / `CS2_34.csv`
- `CS2_35.mat` / `CS2_35.csv`
- `CS2_36.mat` / `CS2_36.csv`
- `CX2_33.mat` / `CX2_33.csv`

## Usage
These dataset files provide continuous dynamic charge/discharge profiles and capacity degradation measurements for model training and cross-validation in the BRAIN analytics engine.

> **Note**: MAT and CSV data files are ignored by `.gitignore`.
